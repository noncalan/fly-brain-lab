## 1. Железные правила (нарушать нельзя)

1. **Никаких выдуманных нейронов.** ID и типы клеток для стимулов/реакций/областей — только из данных FlyWire
   (аннотации `flyconnectome/flywire_annotations` v3.2.0, Codex), из кода Shiu et al., или из форка. У каждого набора
   в `data/NEURON_SETS.md` указан источник. Нет источника — нет функции, спроси меня.
   Роли нейронов из других статей допустимы, только если я разрешил и статья реально открыта и DOI проверен
   (так одобрены MDN, DNp09, DNa02, Giant Fiber — см. §6).
2. **Честность модели.** Поведение включается только по реальной активности конкретных нейронов в симуляции,
   не скриптом. Если модель чего-то не делает — так и показываем («модель не воспроизводит эту реакцию»).
   Анимация, которая не следует из нейронов (траектория полёта, поза), должна быть явно декоративной и
   запускаться только по нейронному триггеру.
3. **Никаких выдуманных цифр и цитат.** Каждое число в документации/интерфейсе указывает на файл с результатом
   (`tools/calibrate/results/`, `tools/probe/results/`, тесты). Каждая ссылка на статью — открыта и сверена.
4. **Секреты.** Никаких токенов в репо. Деплой только через уже залогиненные `vercel` и `gh`.
   `.env.local` (создан `vercel link`, содержит OIDC-токен) в `.gitignore` — не коммитить, не печатать.
5. **Производительность.** Первая загрузка ~≤5 с на нормальном интернете, интерфейс ≥30 FPS на среднем ноутбуке,
   симуляция только в Web Worker.
6. **Лицензии.** Данные FlyWire — CC BY-NC 4.0 → сайт строго некоммерческий (без рекламы и платных функций).
   Код Eon (`eonsystemspbc/fly-brain`, GPL-2.0) — **ничего не копировать**, только сверяться.

### 3.1 Ядро симуляции `src/sim/` (работает в Web Worker)
- `engine.ts` — `Simulator`: событийный LIF с уравнениями **Shiu et al. 2024**:
  `dv/dt=(v_rest−v+g)/τm`, `dg/dt=−g/τs`, точное интегрирование за шаг (как Brian2 `linear`), dt 0.1 мс,
  v_rest −52, порог −45 мВ, τm 20 мс, τs 5 мс, рефрактерность 2.2 мс, задержка 1.8 мс, 0.275 мВ/синапс,
  пуассоновский вход с весом ×250 (у стимулированных нейронов нет рефрактерности), сидированный PRNG mulberry32.
  Обновляются только активные нейроны. API: `step(ms)`, `stimulate(setId, Hz)`, `stimulateIndices(key, idx, Hz)`,
  `silence({setId|neuropil|indices})` (как у Shiu: обнуляет выходы), `clearSilence`, `setPruning({minSynapses,
  weightBits})`, `getActivity()` (spikedIndices, neuropilSpikes, setRatesHz), `connections(neuron)` (топ входов/выходов),
  `reset(seed)`. Параметры с источниками — `params.ts`.
- `format.ts` — формат **FBL1** (CSR) + `loadConnectome` с 3 попытками (ретрай нужен: два воркера, качающие один
  файл одновременно, ловят `ERR_CACHE_WRITE_FAILURE` в Chrome).
- `sim.worker.ts` / `client.ts` / `protocol.ts` — воркер и типизированный клиент; скорость 0..1 от реального
  времени, реальный фактор скорости отдаётся в кадре; `connections` — request/response по `requestId`.
- `behaviors.ts` — `BehaviorMonitor`: поведение включено, если средняя частота считываемого набора за окно > порога.
- Тесты: `engine.test.ts` (синтетика: точная формула, задержка, рефрактерность, торможение, silence, pruning,
  детерминизм), `connectome.test.ts` (реальный граф: эффекты Shiu + golden-снимки на сидах),
  `behaviors.test.ts`, `calibration.test.ts` (пропускается; `CALIBRATE=1 [CALIBRATE_ALL=1] npx vitest run src/sim/calibration.test.ts`).

## 5. Модель: что проверено и что не так (подробно — `docs/MODEL_NOTES.md`)

- Ядро исходного форка **не работало** (веса делились на max 2405 синапсов → медианный вес 0.0005 при пороге 1;
  спайк не проходил ни одного синапса), поведение было скриптом (JS-«драйвы», «виртуальный VNC»). Живой
  flybrain.app = тот же код (ядро побайтно идентично) + Workday-панель. Поэтому ядро заменено на Shiu.
- Воспроизводит Shiu: сахар (набор Shiu, 20 GRN) → MN9 ~50–80 Гц, ~343 активных нейрона (у Shiu «около 400»);
  сахар+горькое → MN9 77 → 8.5 Гц; тень (LC4+LPLC2) → Giant Fiber ~260 Гц; JO wind/gravity → aBN1 ~18 Гц, aDN1 ~2 Гц
  (на полном графе 15 Гц — граф ≥5 ослабляет); вода (LB3a в v783) → MN9 0 Гц (у Shiu было, аннотации поменялись) —
  показывается «модель не воспроизводит».
- Калибровка всех стимулов: `tools/calibrate/results/matrix_all.json`. Соль (LB3d) → MN9 ~90 Гц, вкусовые сенсиллы →
  MN9 ~54 Гц (без цитаты), звук → GF 37.5 Гц (ниже порога). **Ни один сенсорный стимул не включает DNp09 или MDN** —
  ходьба только оптогенетикой. Правый DNp09 → сам подтягивает правый DNa02 → ходьба с поворотом направо (как Bidaye).
- **Подозрение на артефакт:** жара, холод, влажность, все 5 запахов и сахар с обеих сторон зажигают одно большое
  состояние (~8.5 тыс. нейронов, 2–3.4 с CPU на 1 с модели), где левый DNa02 ~60 Гц → муха поворачивает налево.
  Не сверено с Brian2. Показано как вывод модели, задокументировано.
- Скорость: сахар ~×0.8–1 реального времени, касание антенны ~×0.3–0.6, тень ~×0.15–0.4, жара медленнее.
  UI показывает фактическую скорость. Без GPU 3D даёт ~15 FPS; с GPU (Iris Xe) 60 FPS.

## 7. Подводные камни, на которые я уже наступал

- **Хук GateGuard** (ECC) в этой среде: перед первым Bash в сессии и перед созданием каждого нового файла требует
  «факты» (что за файл, кто его вызывает, нет ли аналога, моя дословная инструкция) — просто напиши их и повтори вызов.
  **Любое удаление (rm, git rm) хук блокирует** — не обходить; переносить в `legacy/` через `git mv` или просить меня.
- Скриншоты встроенной панели браузера не захватывают второй WebGL-холст (мозг выглядит пустым) — проверять через
  Playwright с GPU: `chromium.launch({ args: ['--enable-gpu','--use-angle=d3d11','--ignore-gpu-blocklist'] })`.
  Headless без этих флагов рисует WebGL программно (SwiftShader) — FPS нерепрезентативен.
- Полностраничный (`fullPage`) скриншот с двумя WebGL-холстами может зависнуть — снимать вьюпорт.
- В dev-режиме StrictMode монтирует Canvas дважды → в консоли «Context Lost» — это нормально.
- `npx vite` в фоне: `TaskStop` убивает npx, а дочерний vite выживает и держит порт → запускать
  `node node_modules/vite/bin/vite.js --port 5179 --strictPort`, а орфанов гасить `taskkill //PID <pid> //F`
  (PID из `netstat -ano | grep :5179`).
- Конфиг Tailwind не подхватывается уже запущенным dev-сервером — перезапускать.
- Heredoc в Git Bash портит `\\` в JSON → JSON-файлы писать инструментом Write.
- Сразу после деплоя первая загрузка может быть 10–30 с (холодный CDN); прогретая ~2 с.
- Две вкладки/воркера, качающие один большой файл одновременно → `ERR_CACHE_WRITE_FAILURE` (уже лечится ретраем).
- `public/data` манифесты (`*.json`) не должны быть immutable.
- Pickle из интернета грузить только ограниченным unpickler-ом (см. `tools/build-data/build_gait.py`).
